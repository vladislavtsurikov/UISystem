# UISystem

Assembly: `UISystem`

## Why it exists
UISystem provides runtime and editor infrastructure for Unity UI workflows.

## Technical overview
The package contains runtime code, editor tooling, and tests for shared UI system behavior.

This package currently contains: Runtime, Editor, Tests.

## How to use
Add the repository to a Unity project, reference the `UISystem` asmdef from UI modules, and use the runtime or editor APIs in UI workflows.
